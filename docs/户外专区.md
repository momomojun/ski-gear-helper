# 滑雪为主，户外独立

默认首页和第一导航仍是滑雪，原有 22 个滑雪分类、固定器分析和腰宽筛选保留。户外是单独入口，当前增加外套、徒步裤/户外裤、速干衣/户外上衣、徒步鞋/徒步靴、越野跑鞋 5 类。

## 页面与数据

- 滑雪：`#/` 或 `#/c/ski`；户外：`#/outdoor`，分类例如 `#/outdoor/c/trail_shoe`。
- 每个专区独立保存搜索与筛选；户外筛选不会覆盖滑雪设置。
- 抓绒/保暖层、保暖内衣、手套、袜子、帽子、围脖/护脸共享已有商品和历史；仅换入口标签，不复制价格记录。
- “更新滑雪”和“更新户外”分别更新对应范围；自动更新仍优先滑雪。局部户外刷新不推迟滑雪更新。

## 首批来源

| 来源 | 新增范围 | 边界 |
|---|---|---|
| REI | 五类全部 | 男女专用分类页；外套先覆盖雨衣；每类最多 30 个详情，其余可能无逐码价格 |
| Sports Basement | 外套、裤子、上衣、越野鞋 | 已验证的 hiking / trail-running 集合；混有凉鞋的 footwear 集合不接入 |
| Outdoor Gear Exchange (`gearx`) | 徒步鞋 | 已验证的男女 hiking-shoes 集合，当前主要低帮鞋 |

已有来源的可信度记录继续使用；新增集合不等于覆盖整个网站。遵守 robots.txt 和同站限速，遇到访问限制停止。

## 鞋类比较规则

鞋码保留 `码制:男女码基准:尺码:楦宽`，例如 `US:men:9:wide`。界面会显示可读标签；未注明的部分明确保留“未注明”。

不从店铺位于美国推断 US 码，不从数字大小推断 EU 码，不把 US 男女码互换，也不按雪鞋 Mondo 鞋壳规则匹配。只有原始标签、选项名或商品尺码表有明确证据时才记录码制。

男款、女款、儿童与中性鞋分组；GTX/非 GTX、鞋帮高度、型号代数和明确楦宽参与区分。宽度混合的商品页保留每个规格的宽度、颜色、价格、库存和 SKU 链接。证据不足时宁可少合并。

指定尺码后，只比较该码有货且有明确价格的选项。商品整体起价不能代替未知尺码价格。日本/中国鞋款提供手动查询和参考价，购买前核对码制、宽度、防水与版本。

复合男女码等无法无歧义解析的标签保留原文展示，不参与自动尺码匹配。不同网站缺少相同宽度或码制证据时可能分成多张卡片，不以猜测扩大同款范围。

## 维护入口

`skideals/sections.py` 定义专区，`categories.py` 负责分类，`footwear.py` 负责鞋码和版本差异。`config/categories.toml` 记录各站已验证分类页。

定向更新新分类（项目目录运行）：

```powershell
.\.venv\Scripts\python.exe -m skideals crawl rei sportsbasement gearx -c outdoor_jacket -c outdoor_pants -c outdoor_top -c hiking_shoe -c trail_shoe
```
