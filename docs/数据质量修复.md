# 年龄分组与服装来源修复（2026-10-16）

本次优先解决婴幼儿报价进入成人组、混合年龄规格起价错误、服装来源不足这三个问题。

## 年龄与价格规则

- Infants、Toddlers、Baby、Teen 等明确年龄词，以及 3–6M、12M–18M、2T、Youth、Junior 等专用尺码，进入儿童组。S/M/L、普通数字尺码和低价本身不作为儿童证据。
- 头盔、雪镜、固定器等通用品类也核对商品类型、儿童标签和分类提示；全站同时包含 Men/Women/Kids 的标签不用于强判年龄。
- 同页 Adult/Junior 规格拆成独立报价，分别计算各自有货最低价、原价、库存。共用标题含 Junior 时，成人规格仍保持成人分区。缺少逐规格价格的部分保留待核实，不沿用整页儿童起价。
- 抓取与 `renormalize` 共用年龄证据；保留原始分类提示与年龄分区信息。整理完成后递增目录版本，使网页缓存能看到修复后的分组。
- 原始历史记录保留，但旧 Adult/Youth 混合起价不参与某一独立年龄组的历史最低价。各商家较低的明确原价也不会被同组较高的参考原价抬高。
- 选择尺码后，卡片、详情、库存状态、购买 URL 和关注提醒使用该尺码的已知价格；缺价不回退到其他尺码起价。历史曲线和国际参考报价明确标为任意尺码起价。
